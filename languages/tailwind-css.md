## Tailwind CSS — histoire

- 2017 : créé par Adam Wathan comme alternative aux frameworks CSS à composants préfabriqués.
- Conçu autour du principe “utility-first”.
- Diffusé via un écosystème open source orienté productivité.
- Adoption croissante avec la montée des architectures front-end modernes.
- Évolution continue centrée sur la performance et la flexibilité.

## Tailwind CSS — utilité

- Framework CSS utilitaire basé sur des classes atomiques.
- Permet de construire des interfaces sans écrire de CSS personnalisé.
- Favorise un design cohérent directement dans le balisage.
- Optimisé pour les performances via la génération conditionnelle des styles.
- Utilisé pour des interfaces web modernes, modulaires et hautement personnalisables.
