## Prisma Client — histoire

- Introduit avec Prisma 2 comme composant central de l’architecture Prisma moderne.
- Conçu pour remplacer les approches ORM dynamiques traditionnelles.
- Basé sur la génération automatique de code à partir d’un schéma déclaratif.
- Développé pour s’intégrer naturellement à TypeScript.
- Évolue avec chaque version de Prisma pour suivre les standards JavaScript.

## Prisma Client — utilité

- Client de base de données généré automatiquement.
- Fournit une API typée pour interagir avec les tables et relations.
- Permet requêtes, insertions, mises à jour et suppressions structurées.
- Réduit les erreurs grâce au typage statique.
- Utilisé dans les applications backend Node.js et TypeScript.
