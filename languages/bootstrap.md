## Bootstrap — histoire

- 2011 : créé par des ingénieurs de Twitter pour standardiser et accélérer le développement d’interfaces web internes.
- Publié ensuite en open source pour un usage public.
- Rapidement adopté grâce à sa simplicité et sa cohérence visuelle.
- Évolutions successives vers une architecture plus modulaire et responsive.
- Maintenu comme l’un des frameworks CSS les plus diffusés.

## Bootstrap — utilité

- Framework front-end basé sur CSS et JavaScript.
- Fournit une grille responsive et des composants d’interface prêts à l’emploi.
- Standardise les interfaces pour réduire les écarts de rendu entre navigateurs.
- Accélère le prototypage et le développement d’interfaces web.
- Utilisé pour des sites, des dashboards et des applications web généralistes.
