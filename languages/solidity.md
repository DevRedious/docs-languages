## Solidity — histoire

- 2014 : conçu pour développer des contrats intelligents sur la blockchain Ethereum.
- Créé par l’équipe fondatrice d’Ethereum afin de fournir un langage dédié aux applications décentralisées.
- Inspiré par JavaScript, C++ et Python pour faciliter son adoption.
- Devenu le standard dominant du développement sur Ethereum.
- Évolue en parallèle des besoins de sécurité et des avancées de l’écosystème blockchain.

## Solidity — utilité

- Langage de programmation destiné aux contrats intelligents.
- Permet de définir des règles exécutées automatiquement sur une blockchain.
- Utilisé pour les applications décentralisées (DApps).
- Sert à créer tokens, systèmes de gouvernance et protocoles financiers décentralisés.
- Optimisé pour l’exécution dans l’environnement Ethereum Virtual Machine (EVM).
