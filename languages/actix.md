## Actix — histoire

- 2017 : créé dans l’écosystème Rust comme framework orienté acteurs.
- Inspiré du modèle acteur pour la concurrence et la distribution.
- Développé pour exploiter les garanties de sûreté et de performance de Rust.
- Extension majeure avec Actix Web pour les services HTTP.
- Adoption dans les services backend à haute performance.

## Actix — utilité

- Framework Rust pour systèmes concurrents basés sur le modèle acteur.
- Fournit une gestion structurée des tâches et messages asynchrones.
- Utilisé pour construire des services réseau et backend performants.
- Actix Web permet la création d’API et serveurs HTTP rapides.
- Adapté aux architectures nécessitant forte concurrence et faible latence.
