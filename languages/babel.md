## Babel — histoire

- Créé pour résoudre les incompatibilités entre versions modernes de JavaScript et navigateurs plus anciens.
- Initialement connu sous le nom 6to5 avant d’être renommé Babel.
- Développé avec l’essor rapide des nouvelles fonctionnalités ECMAScript.
- Adoption massive dans l’écosystème front-end moderne.
- Évolue en parallèle des standards JavaScript.

## Babel — utilité

- Transpileur JavaScript.
- Convertit du code moderne en versions compatibles avec davantage d’environnements.
- Permet l’utilisation anticipée de fonctionnalités ECMAScript récentes.
- S’intègre aux outils de build et frameworks front-end.
- Utilisé pour assurer compatibilité et portabilité des applications web.
