## Xojo — histoire

- 1998 : origine sous le nom REALbasic, conçu pour simplifier le développement d’applications desktop.
- Développé par la société REAL Software, puis renommé Xojo en 2013.
- Conçu pour permettre un développement rapide avec une interface visuelle.
- Extension progressive vers le web et le mobile.
- Maintenu comme environnement de développement multiplateforme.

## Xojo — utilité

- Environnement de développement intégré avec langage propriétaire.
- Permet de créer des applications desktop, web et mobiles.
- Basé sur une approche visuelle avec glisser-déposer.
- Génère des applications natives pour plusieurs systèmes.
- Utilisé pour le développement rapide d’applications métier et outils internes.
