## Node.js — histoire

- 2009 : créé par Ryan Dahl pour exécuter JavaScript hors navigateur.
- Conçu pour gérer efficacement des opérations réseau concurrentes.
- Introduit un modèle d’exécution non bloquant basé sur les événements.
- Adoption rapide dans le développement backend moderne.
- Évolution continue au sein de l’écosystème JavaScript.

## Node.js — utilité

- Environnement d’exécution JavaScript côté serveur.
- Optimisé pour les applications réseau et temps réel.
- Permet la création d’API et de services backend performants.
- Partage un langage commun entre client et serveur.
- Pilier des architectures web modernes.
