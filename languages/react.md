## React — histoire

- 2013 : créé par Facebook pour gérer des interfaces utilisateurs complexes et dynamiques.
- Conçu pour résoudre les problèmes de mise à jour inefficace du DOM.
- Introduit le concept de composants réutilisables.
- Diffusé massivement via l’open source et adopté par l’industrie.
- Évolue continuellement avec l’écosystème JavaScript moderne.

## React — utilité

- Bibliothèque JavaScript dédiée à la construction d’interfaces utilisateur.
- Basée sur une architecture orientée composants.
- Optimise le rendu via une abstraction du DOM.
- Facilite la gestion d’états et d’interactions complexes.
- Utilisée pour des applications web riches et interactives.
