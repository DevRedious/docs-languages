## Leptos — histoire

- Créé dans l’écosystème Rust pour proposer un framework web réactif moderne.
- Conçu pour exploiter les performances et la sûreté mémoire de Rust.
- Inspiré par les frameworks JavaScript réactifs contemporains.
- Adoption progressive dans les projets WebAssembly et full-stack Rust.
- Évolution continue autour du rendu réactif et du SSR.

## Leptos — utilité

- Framework Rust pour interfaces web réactives.
- Permet le rendu côté client et côté serveur.
- Compatible avec WebAssembly pour exécution dans le navigateur.
- Optimisé pour la performance et la sécurité mémoire.
- Utilisé pour des applications web modernes dans l’écosystème Rust.
