## TypeScript — histoire

- 2012 : créé par Microsoft pour renforcer JavaScript par un système de types statiques.
- Conçu pour faciliter la maintenance des bases de code complexes.
- S’appuie entièrement sur JavaScript et en reste un sur-ensemble compatible.
- Adoption rapide dans les projets d’envergure et les frameworks modernes.
- Évolution continue alignée sur les standards ECMAScript.

## TypeScript — utilité

- Langage de programmation typé se compilant en JavaScript.
- Réduit les erreurs à l’exécution par la vérification statique.
- Améliore la lisibilité et la prévisibilité du code.
- Favorise l’outillage avancé (autocomplétion, refactoring).
- Utilisé massivement pour les applications web et les projets structurés.
