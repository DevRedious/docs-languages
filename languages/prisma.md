## Prisma — histoire

- 2016 : lancé initialement sous le nom Graphcool comme plateforme backend.
- Repositionné ensuite comme outil de gestion de base de données pour JavaScript et TypeScript.
- Conçu pour simplifier l’accès aux bases relationnelles.
- Adoption croissante avec la montée des architectures modernes full-stack.
- Évolution continue centrée sur la productivité et la sécurité des données.

## Prisma — utilité

- ORM moderne pour Node.js et TypeScript.
- Fournit un schéma déclaratif pour modéliser la base de données.
- Génère un client typé pour interagir avec les données.
- Simplifie migrations et gestion des relations.
- Utilisé dans les applications web nécessitant accès structuré et sécurisé aux données.
