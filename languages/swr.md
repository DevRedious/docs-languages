## SWR — histoire

- Créé par l’équipe de Vercel pour simplifier la gestion des données côté client.
- Inspiré par la stratégie de cache HTTP “stale-while-revalidate”.
- Développé pour les applications React modernes.
- Adoption progressive avec l’essor des architectures front-end réactives.
- Évolution continue dans l’écosystème React et Next.js.

## SWR — utilité

- Bibliothèque React de récupération et mise en cache de données.
- Met à jour automatiquement les données en arrière-plan.
- Optimise performances et réactivité des interfaces.
- Simplifie la synchronisation entre client et serveur.
- Utilisé pour les applications web nécessitant données dynamiques et temps réel léger.
