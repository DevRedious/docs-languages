## Vue — histoire

- 2014 : créé par Evan You après son expérience sur des projets front-end complexes.
- Conçu pour être progressif et facilement intégrable.
- Diffusé en open source avec une adoption communautaire rapide.
- Évolutions majeures vers une architecture plus modulaire et performante.
- Maintenu activement dans l’écosystème front-end moderne.

## Vue — utilité

- Framework JavaScript pour la construction d’interfaces utilisateur.
- Basé sur des composants réactifs.
- Permet une intégration progressive dans des projets existants.
- Facilite la gestion de l’état et du rendu.
- Utilisé pour des applications web interactives et maintenables.
