## Vite — histoire

- 2020 : créé par Evan You pour répondre aux lenteurs des outils de build front-end traditionnels.
- Conçu initialement pour l’écosystème Vue, puis étendu à d’autres frameworks.
- Basé sur les capacités natives des navigateurs modernes.
- Adoption rapide dans le développement front-end moderne.
- Évolution continue orientée performance et simplicité.

## Vite — utilité

- Outil de développement et de build pour applications front-end.
- Fournit un serveur de développement ultra-rapide.
- Utilise le chargement de modules natifs en développement.
- Produit des builds optimisés pour la production.
- Utilisé avec des frameworks modernes pour accélérer le cycle de développement.
