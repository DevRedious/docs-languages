## SQL — histoire

- Années 1970 : dérivé des travaux de recherche sur les bases de données relationnelles.
- Conçu pour manipuler des données organisées en tables reliées.
- Standardisé progressivement pour assurer la portabilité entre systèmes.
- Adopté par la majorité des systèmes de gestion de bases de données.
- Évolue par extensions propres à chaque moteur.

## SQL — utilité

- Langage déclaratif de gestion de bases de données relationnelles.
- Permet la lecture, l’insertion, la modification et la suppression de données.
- Définit schémas, contraintes et relations.
- Utilisé pour les requêtes analytiques et transactionnelles.
- Socle des applications reposant sur des données structurées.
