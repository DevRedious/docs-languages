## PHP — histoire

- 1995 : créé par Rasmus Lerdorf pour gérer des pages web dynamiques.
- Initialement conçu comme un ensemble de scripts personnels.
- Évolution rapide vers un langage serveur complet.
- Large diffusion avec l’essor des sites dynamiques et des CMS.
- Maintenu et standardisé sur plusieurs décennies.

## PHP — utilité

- Langage de programmation interprété côté serveur.
- Spécialisé dans la génération de contenu web dynamique.
- Étroitement intégré aux serveurs web et bases de données.
- Utilisé massivement dans les CMS et applications web.
- Présent dans une grande partie de l’infrastructure web existante.
