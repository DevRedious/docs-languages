## Ruby on Rails — histoire

- 2004 : créé par David Heinemeier Hansson comme framework web basé sur Ruby.
- Issu d’un besoin de productivité rapide pour des applications web complètes.
- Popularisé dès le milieu des années 2000 par son approche radicalement simplificatrice.
- A fortement influencé la conception de nombreux frameworks web ultérieurs.
- Maintenu et enrichi en continu au sein de l’écosystème Ruby.

## Ruby on Rails — utilité

- Framework web complet pour le développement d’applications côté serveur.
- Repose sur des conventions fortes pour réduire la configuration manuelle.
- Intègre nativement les couches essentielles : routing, contrôleurs, vues, modèles.
- Accélère la création d’applications CRUD et de plateformes métier.
- Utilisé pour des applications web structurées, évolutives et maintenables.
