## Dioxus — histoire

- Créé dans l’écosystème Rust pour développer des interfaces utilisateur multiplateformes.
- Inspiré par l’approche composant et déclarative de React.
- Conçu pour unifier web, desktop et mobile autour de Rust.
- Adoption progressive dans les projets Rust UI modernes.
- Évolution continue autour de la performance et de la portabilité.

## Dioxus — utilité

- Framework Rust orienté interfaces utilisateur réactives.
- Permet le développement web, desktop et mobile.
- Basé sur des composants déclaratifs et un système réactif.
- Compatible avec WebAssembly pour les applications web.
- Utilisé pour des applications multiplateformes dans l’écosystème Rust.
