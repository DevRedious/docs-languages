## Prisma Studio — histoire

- Introduit comme outil complémentaire dans l’écosystème Prisma.
- Conçu pour faciliter l’inspection visuelle des bases relationnelles.
- Développé pour fonctionner directement avec le schéma Prisma.
- Intégré progressivement comme utilitaire standard du workflow Prisma.
- Maintenu comme interface légère de gestion de données.

## Prisma Studio — utilité

- Interface graphique pour visualiser et modifier les données.
- Permet la navigation dans les tables et relations.
- Autorise l’édition manuelle des enregistrements.
- Fonctionne localement sans configuration complexe.
- Utilisé pour le débogage, les tests et la gestion rapide de données.
