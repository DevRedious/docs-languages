## Tauri — histoire

- 2020 : lancé comme alternative légère aux frameworks desktop basés sur des moteurs embarqués lourds.
- Conçu pour exploiter les capacités natives du système plutôt qu’un navigateur complet intégré.
- Basé sur Rust pour la couche backend et sécurité mémoire.
- Adoption croissante avec la recherche d’applications desktop plus performantes et légères.
- Évolution continue dans l’écosystème des outils modernes.

## Tauri — utilité

- Framework pour créer des applications desktop multiplateformes.
- Combine interface web (HTML, CSS, JavaScript) avec backend natif en Rust.
- Produit des exécutables légers avec faible consommation mémoire.
- Offre une sécurité renforcée grâce au modèle Rust.
- Utilisé pour des applications desktop modernes et performantes.
