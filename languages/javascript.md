## JavaScript — histoire

- 1995 : créé par Brendan Eich en quelques jours pour le navigateur Netscape.
- Conçu initialement pour apporter de l’interactivité aux pages web statiques.
- Rapidement standardisé sous le nom ECMAScript pour éviter les divergences.
- Années 2010 : transformation majeure avec l’émergence des applications web riches.
- Aujourd’hui : langage central du Web, présent côté navigateur et côté serveur.

## JavaScript — utilité

- Langage de programmation interprété et dynamique.
- Gère le comportement et l’interactivité des interfaces web.
- Permet la manipulation du DOM et la communication asynchrone.
- Utilisé côté client et côté serveur via des environnements dédiés.
- Pilier des applications web modernes et des écosystèmes associés.
