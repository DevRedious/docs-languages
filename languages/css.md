## CSS — histoire

- 1994 : proposition initiale pour séparer la présentation visuelle du contenu HTML.
- 1996 : première normalisation officielle (CSS niveau 1) pour unifier les styles sur le Web.
- Fin des années 1990 : CSS 2 introduit le positionnement, les médias et une meilleure typographie.
- Années 2010 : adoption massive de CSS3, structuré en modules indépendants (layout, animations, couleurs).
- Aujourd’hui : standard évolutif central pour le rendu visuel du Web moderne.

## CSS — utilité

- Langage de feuilles de style destiné à définir l’apparence des documents HTML.
- Contrôle la mise en page, les couleurs, les typographies, les espacements et les animations.
- Permet la séparation stricte entre structure (HTML) et présentation.
- Rend possible le design responsive pour tous les formats d’écran.
- Pilier de la cohérence visuelle, de la maintenabilité et des performances côté client.
