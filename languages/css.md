## CSS — histoire

- 1994 : proposition initiale par Håkon Wium Lie pour séparer la présentation visuelle du contenu HTML.
- 1996 : première recommandation officielle (CSS niveau 1) publiée par le W3C pour unifier les styles sur le Web.
- Fin des années 1990 : CSS 2 introduit le positionnement précis, les types de médias et une typographie enrichie.
- Années 2010 : adoption massive de CSS3, structuré en modules indépendants (Flexbox, Grid, animations, variables).
- Aujourd’hui : standard évolutif central et modulaire pour le rendu visuel et le design responsive du Web moderne.

## CSS — utilité

- Langage de feuilles de style destiné à définir l’apparence et la mise en page des documents HTML.
- Contrôle la disposition, les couleurs, les typographies, les espacements, les transitions et les animations.
- Permet la séparation stricte entre structure de contenu (HTML) et présentation visuelle.
- Rend possible le responsive design pour adapter l'affichage à tous les types d'écrans et d'appareils.
- Pilier de la cohérence visuelle, de la maintenabilité et de l'expérience utilisateur côté client.
