## tRPC — histoire

- Créé pour simplifier la communication entre front-end et back-end TypeScript.
- Développé dans l’écosystème JavaScript moderne orienté typage fort.
- Conçu comme alternative aux API REST fortement répétitives.
- Adoption progressive dans les architectures full-stack TypeScript.
- Évolution continue autour de la sécurité de typage et de la productivité.

## tRPC — utilité

- Bibliothèque de communication client-serveur typée.
- Permet des appels de procédures distantes sans génération manuelle de schémas.
- Partage automatiquement les types entre front-end et back-end.
- Réduit la duplication et les erreurs de synchronisation API.
- Utilisé dans les applications full-stack TypeScript modernes.
