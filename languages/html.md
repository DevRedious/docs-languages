## HTML — histoire

- 1991 : conçu par Tim Berners-Lee pour structurer et relier des documents sur le World Wide Web.
- Début des années 1990 : évolution rapide pour répondre aux besoins de publication scientifique et institutionnelle.
- 1995–2000 : normalisation progressive pour limiter les divergences entre navigateurs.
- Années 2010 : HTML5 unifie les pratiques modernes du Web (multimédia, formulaires avancés, sémantique).
- Aujourd’hui : standard vivant maintenu en continu, fondation stable du Web.

## HTML — utilité

- Langage de balisage destiné à décrire la structure d’un document, non son comportement ni son style.
- Définit le sens du contenu : titres, sections, articles, navigation, formulaires, médias.
- Sert de base commune interprétable par tous les navigateurs.
- Permet l’accessibilité, le référencement et l’interopérabilité des contenus.
- Constitue la couche structurelle sur laquelle reposent CSS (présentation) et JavaScript (logique).
