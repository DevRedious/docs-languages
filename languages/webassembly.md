## WebAssembly — histoire

- 2017 : standardisé pour améliorer les performances des applications web complexes.
- Conçu par plusieurs acteurs majeurs du Web pour compléter JavaScript.
- Développé afin d’exécuter du code compilé directement dans le navigateur.
- Adoption progressive dans les domaines nécessitant fortes performances.
- Évolution continue vers des usages web et hors navigateur.

## WebAssembly — utilité

- Format binaire portable destiné à l’exécution haute performance.
- Permet d’exécuter des langages compilés dans les navigateurs.
- Complète JavaScript pour les traitements intensifs.
- Utilisé pour jeux, rendu 3D, calcul scientifique et applications lourdes.
- Présent dans des environnements web, desktop et edge modernes.
