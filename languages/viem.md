## Viem — histoire

- Créé pour offrir une alternative moderne aux bibliothèques historiques de l’écosystème Ethereum.
- Développé avec une forte orientation TypeScript et sécurité de typage.
- Conçu pour simplifier les interactions avec les blockchains compatibles EVM.
- Adoption croissante dans les applications Web3 modernes.
- Évolution continue en parallèle des standards Ethereum.

## Viem — utilité

- Bibliothèque TypeScript pour interagir avec les blockchains EVM.
- Permet la lecture et l’écriture de données sur la blockchain.
- Gère comptes, transactions, événements et contrats intelligents.
- Fournit un typage strict pour réduire les erreurs de développement.
- Utilisée dans les applications décentralisées, portefeuilles et services Web3.
