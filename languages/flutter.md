## Flutter — histoire

- 2015 : initié par Google comme framework de développement multiplateforme.
- Conçu pour produire des interfaces natives à partir d’une base de code unique.
- Diffusé publiquement en open source et stabilisé progressivement.
- Adoption accrue avec la montée des applications mobiles multiplateformes.
- Évolution continue autour de la performance et de l’unification des plateformes.

## Flutter — utilité

- Framework UI multiplateforme basé sur le langage Dart.
- Permet de créer des applications mobiles, web et desktop.
- Utilise un moteur de rendu propre pour un contrôle total de l’interface.
- Offre des performances proches du natif.
- Utilisé pour des applications produits, mobiles et cross-platform.
