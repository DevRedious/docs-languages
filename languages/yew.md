## Yew — histoire

- Créé dans l’écosystème Rust pour apporter une approche moderne du développement front-end.
- Inspiré par les frameworks JavaScript basés sur des composants réactifs.
- Développé autour de WebAssembly pour exécuter Rust dans le navigateur.
- Adoption progressive dans les projets web Rust.
- Évolution continue centrée sur les performances et la sûreté mémoire.

## Yew — utilité

- Framework front-end Rust pour applications web.
- Basé sur des composants et un rendu réactif.
- Compile vers WebAssembly pour exécution côté navigateur.
- Permet la création d’interfaces web performantes et typées.
- Utilisé dans les applications web modernes de l’écosystème Rust.
